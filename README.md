# Waze-Project
Waze’s free navigation app makes it easier for drivers around the world to get to where they want to go. Waze’s community of map editors, beta testers, translators, partners, and users helps make each drive better and safer. Waze partners with cities, transportation authorities, broadcasters, businesses, and first responders to help as many people as possible travel more efficiently and safely.

 ## This project focuses on monthly user churn.
Churn quantifies the number of users who have uninstalled the Waze app or stopped using the app. Developing a churn prediction model will help prevent churn, improve user retention, and grow Waze’s business.

## Data Source 📖

**Dataset**: Waze Dataset from Google Advanced Data Analytics Professional Certificate
**Source**: [Kaggle](https://www.kaggle.com/datasets/jakubpolcsk/waze-dataset)

## Motivation 🧠
As a data analyst driven by real-world problem solving, this user dataset is a great opportunity to dig into exploratory analysis, build predictive models, and turn insights into data-driven decisions.

## Key Questions ⁉️ 🤔
An accurate model can also help identify specific factors that contribute to churn and answer questions such as: 

✅Who are the users most likely to churn?

✅Why do users churn? 

✅When do users churn?
